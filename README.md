# Moodle Downloader for macOS

Нативное приложение для скачивания доступных студенту материалов курсов с
`moodle.innopolis.university`. Приложение не запрашивает и не хранит пароль:
вход выполняется в обычном окне Moodle внутри приложения.

## Запуск для разработки

Требуется macOS 13+ и Swift 6 (достаточно Command Line Tools):

```bash
swift run MoodleDownloader
```

## Сборка `.app`

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open "dist/Moodle Downloader.app"
```

## Использование

1. При первом запуске войдите в Moodle (включая SSO/2FA, если требуется).
2. При следующих запусках сохранённая WebKit-сессия откроет **My courses** автоматически.
3. Выберите предмет и отметьте нужные уроки или темы.
4. Выберите папку назначения и формат (папка или ZIP).
5. Нажмите **Скачать выбранные уроки**.

Пароль приложение не получает и не сохраняет. Moodle может периодически завершать
сессию; тогда безопасный экран входа появится снова.

Структура результата: `<Предмет>/<номер> — <тема>/<материал.ext>`. Названия с
`Lab 1`, `Lecture 2` и похожими обозначениями нормализуются. Одинаковые имена
не перезаписываются — к следующему файлу добавляется `(2)`.

Загружаются только файлы, доступные текущей учётной записи. Приложение не
обходит ограничения Moodle и не скачивает ответы, оценки или содержимое тестов.

## Если Moodle поменял разметку

Разметка и плагины Moodle могут различаться. Для адаптации без передачи пароля
достаточно прислать:

- скриншот страницы одного курса с раскрытыми темами;
- HTML страницы курса, сохранённый браузером после входа;
- примеры типов материалов, которые не скачались (Resource, Folder, Page и т. п.).

Перед отправкой HTML можно удалить имя, email, оценки и другие личные данные.
HTML можно сохранить кнопкой **Сохранить HTML** в верхней панели приложения.
